
# Fanaoka
### Stop pub — Économisez vos données mobiles.

Fanaoka est une application Android gratuite destinée à réduire la consommation de données mobiles et à limiter les publicités et les traceurs.

## Notre objectif
- Réduire la consommation Internet.
- Limiter les publicités intrusives.
- Protéger la vie privée.
- Fonctionner sur les téléphones Android modestes.
- Ne demander aucun abonnement ni paiement.

## Principes
- Pas de publicité intégrée à Fanaoka.
- Pas de collecte inutile de données personnelles.
- Pas d'historique de navigation collecté.
- Pas d'interception ni de déchiffrement HTTPS.

## Développement
Version : Alpha 0.1

Appareil de référence : Itel A665L — Android 13.
Réseau de référence : Telma — Madagascar.

Le moteur de filtrage est encore en développement. Les fonctions de blocage global et les économies de données devront être vérifiées par des tests réels.

## Projet
Fanaoka est un projet indépendant, gratuit et ouvert à son amélioration progressive.
